## ⚡ DTB-Apex V1.0 五大核心量化机制

1. **8.0% 相对溢价硬顶熔断 (DPSA)**：
   * 追踪 159509 相对 513100 的 20 日偏离度；
   * 当溢价偏离 $> 8.0\%$ 触发散户非理性狂热时，系统果断 100% 切换至 513100 避险，彻底规避溢价踩踏崩盘！
2. **美涨A跌杀溢价错位低吸引擎 (Dislocation Sniper)**：
   * 隔夜美股趋势健康但 A 股恐慌砸盘杀溢价（相对偏离 $< -1.5\%$）时，自动触发满额低吸捡便宜筹码！
3. **极端情绪反向加速收割 (Reverse Euphoria Harvesting)**：
   * 科技大涨市值超配 ($\ge 56\%$) 且溢价 $> 8\%$ 时，多卖 4% 泡沫筹码直接锁定进免税农业银行与黄金！
4. **ATR-Keltner 动量接力引擎**：
   * 突破 $Close > EMA_{20} + 0.3 \times ATR_{20}$ 且 $RSI > 50$ 且溢价安全时，满额享受 159509 芯片算力爆发！
5. **黄金避险虹吸自愈 (Gold Siphon)**：
   * 在全球黑天鹅股灾爆发、纳指极度超跌且黄金避险大涨时，自动将黄金高位盈利平滑回补科技底仓。

## ⏰ GitHub Actions 全自动定时提醒配置指南

在 `.github/workflows/daily_strategy_alert.yml` 中已配置双通道自动调度：
1. **每个交易日 14:45 CST** (收盘前 15 分钟) - 盘中黄金决策窗口；
2. **每天晚上 21:00 CST** (晚上 9 点整) - 待全市场公募基金净值更新完毕后的晚间全景复盘报告。

### 支持的多渠道推送配置
在 GitHub 仓库中进入 **Settings -> Secrets and variables -> Actions -> New repository secret**，添加以下任意 Key 即可开启免维护云端推送：

| Secret 变量名 | 说明 | 获取方式 |
| :--- | :--- | :--- |
| `WECOM_WEBHOOK` | 企业微信群机器人 Webhook | 企业微信群 -> 添加群机器人 -> 复制 Webhook 地址 |
| `PUSHPLUS_TOKEN` | PushPlus 微信推送 Token | [pushplus.plus](http://www.pushplus.plus/) 扫码获取 Token |
| `DINGTALK_WEBHOOK` | 钉钉群自定义机器人 Webhook | 钉钉群 -> 智能群助手 -> 自定义机器人 -> 复制 Webhook |
| `FEISHU_WEBHOOK` | 飞书群自定义机器人 Webhook | 飞书群 -> 设置 -> 群机器人 -> 自定义机器人 -> 复制 Webhook |
